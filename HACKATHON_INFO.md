# Agents for Humans Hackathon (Devpost)

## Key Competition Parameters
- **Sponsor**: Amazon / AWS
- **Platform**: [Devpost](https://agentsforhumans.devpost.com)
- **Total Cash Prizes**: **$40,000**
- **Submission Deadline**: **September 14, 2026 at 20:00 EDT**
- **Mandatory Technology**: Built with **Strands Agents SDK** (`strands-agents`)
- **License Requirement**: Open Source (MIT or Apache 2.0)

---

## The Challenge & Theme
> *"Every day, people lose hours to small, repetitive tasks like paying bills, scheduling meetings, or filling out the same paperwork again. Build an AI agent with the Strands Agents SDK that handles routine and repetitive tasks in the background. Instead of another app people open and manage, the agent runs autonomously and only surfaces when there's a real decision to make."*

### Selected Competition Track
**Track 1: Everyday Agents**
- *Description*: An agent that takes the busywork out of daily life, errands, career logistics, and paperwork. Runs quietly in the background and only pings when there is a real decision to make.
- *Our Project Positioning*: **JobAgent — Autonomous Background Career CRM & Compliance Engine**.
  Job hunting across multiple portals creates fragmented emails, lost job postings, repetitive form filling, and tedious government compliance logging. JobAgent runs in the background, tags emails in Gmail, detects interview invitations, preserves visual snapshots of job postings, and auto-generates official compliance reports.

---

## Submission Deliverables Required
1. **Public Code Repository**: Complete source code, setup instructions, and open-source license.
2. **README**: Clear documentation of what the agent does, architecture, and quickstart.
3. **Architecture Diagram**: High-level visual diagram showing agent tools, ingestion protocols, and local storage.
4. **Demo Video**: Maximum 5 minutes showing the agent running end-to-end.
5. **Project Story**: Background, problem, solution, and impact.
